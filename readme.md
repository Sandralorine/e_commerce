# 👗 LUXAMODE - Projet de Web Design

Bienvenue sur le dépôt de **LUXAMODE**, un projet de site e-commerce fictif dédié à la mode et aux accessoires. Ce projet a été réalisé dans le cadre d'un cours de **Web Design**. 

Contrairement à un projet fullstack, l'objectif ici était de se concentrer exclusivement sur **l'aspect visuel et l'expérience utilisateur (UI/UX)** en utilisant les technologies front-end de base.

## ✨ Fonctionnalités & Points forts

Ce site a été conçu pour démontrer la maîtrise des techniques de mise en page et d'interaction :

*   **🖥️ Mega Menu interactif** : Un menu de navigation riche au survol, permettant de dérouler les catégories (Bijoux, Accessoires, Vêtements) et sous-catégories pour une navigation fluide.
*   **🖼️ Galerie Produits Dynamique** : Une page catalogue avec un affichage en grille des produits, badges de réduction (ex: -14%) et boutons "Ajouter" pour simuler le panier.
*   **🔍 Zoom sur l'image** : Sur la page de détails d'un article, la possibilité de survoler l'image principale pour zoomer et voir les détails du tissu ou du bijou.
*   **💳 Simulation de Paiement** : Une page de panier ("Mon Panier") avec un récapitulatif clair (Sous-total, Livraison) et un bouton "Paiement" pour simuler le processus de commande.
*   **📱 Design Responsive** : Le site s'adapte aux différentes tailles d'écran grâce à Bootstrap.

## 📄 Structure des pages

Le site est composé de plusieurs pages clés démontrant les compétences en intégration :

1.  **🏠 Page d'Accueil**
    *   Bannière principale avec carrousel d'images (promotions).
    *   Section "Bienvenue chez Luxamode".
    *   Mise en avant des catégories populaires.

2.  **🛍️ Page "Tous les produits"**
    *   Catalogue complet avec filtres visuels.
    *   Affichage des cartes produits (image, nom, prix, badge de réduction).
    *   Menu latéral listant les types de produits et perettant d effectuer un filtrage (Pantalon, Chemise, Robe, etc.).

3.  **🔎 Page "Détails du produit"**
    *   Image du produit  (avec effet de zoom).
    *   Informations détaillées (Catégorie, Prix, Taille disponible, Description).
    *   Bouton "Ajouter au panier".
    *   Images des produits simulaires.


4.  **🛒 Page "Panier"**
    *   Liste des articles sélectionnés avec images miniatures.
    *   Option pour supprimer un article ou modifier la quantité.
    *   Récapitulatif de la commande (Total, Livraison).
    *   Simulation de paiement avec les logos des moyens de paiement (Mobile Money, etc.).

## 🚀 Technologies utilisées

Ce projet est **100% Front-end** (pas de base de données ni de serveur backend) :

*   **HTML5** (Structure des pages)
*   **CSS3** (Mise en page avancée, animations, effet de zoom)
*   **Bootstrap** (Framework CSS pour le responsive et les composants comme le carrousel)
